DepVet

Know a dependency before you adopt it.

Every claim gets a source. Conflicts stay visible.

Paste a GitHub repo link or a package name. DepVet returns a sourced risk brief: security history, maintenance health, licence, and a clear adopt, caution, or avoid verdict.

Try a sample:
Step 1

Evidence from primary records

GitHub gives the repo record and upkeep signals. OSV gives the advisory history. Tavily searches the live web for incidents and project notices.

Step 2

Nano classifies the evidence

NVIDIA Nemotron 3 Nano, the fast model, reads the collected evidence and sorts each claim under security, maintenance, licence, or incidents.

Step 3

Ultra writes the verdict

NVIDIA Nemotron 3 Ultra checks the claims for conflicts and writes the verdict from cited claims only. Both models run on Nebius Token Factory.
